## R-ZOBFKZ. 랜딩 페이지 및 서비스 안내

Finsight의 핵심 가치, 지원 파일 형식, AI가 제공하는 분석 항목, 무료 월 2회 분석 정책, 월간 구독
결제 및 로그인 진입점을 안내하는 랜딩 페이지를 제공한다.

**Acceptance Criteria**
- CSV/PDF 카드 내역서 업로드 지원 안내
- 카테고리별 지출, 이상 지출, 절약·관리 추천 제공 안내
- 무료 월 2회 분석, 유료 월간 구독 시 추가 분석 정책 명시
- 로그인/회원가입 화면으로 이동 가능
- 금융 비전문가도 이해 가능한 문장 수준

### F-MVOOAK. 핵심 가치 및 분석 결과 안내

로그인 없이도 접근 가능한 랜딩 페이지에서 서비스의 핵심 가치를 설명한다. 실제 분석/개인화된
결과 제공은 로그인 후 대시보드 범위.

- **Precondition**: 방문자는 로그인하지 않은 상태에서도 랜딩 페이지에 접근할 수 있다.
- **Trigger**: 방문자가 랜딩 페이지에 접속한다.
- **Action**: AI 소비 분석이 해결하는 문제와 가치를 설명하고, 카테고리별 지출·이상 지출·절약
  추천 항목을 안내한다.
- **Outcome**: 방문자는 Finsight가 카드 내역 기반 소비 현황·관리 포인트를 알려주는 서비스임을
  이해한다.
- **Exceptions**: 서비스 설명만으로는 개인별 분석 결과나 금융 의사결정 정보를 제공하지 않는다.
- **Display**: 쉬운 문장으로 표시, 카테고리별 지출/이상 지출/절약 추천은 서로 구분해서 표시.
- **Permissions**: 모든 방문자가 볼 수 있다.
- **Rules**: 투자·대출·보험 등 전문 금융 의사결정 서비스로 표현하지 않는다. 소비 관리 참고
  정보라는 범위를 벗어나지 않는다.
- **Data**: 정적 콘텐츠.

### F-ENLUHX. 지원 파일 형식 및 이용 정책 안내

- **Precondition**: 방문자는 랜딩 페이지에서 서비스 이용 조건을 확인할 수 있다.
- **Trigger**: 방문자가 서비스 이용 방법/요금 안내 영역을 확인한다.
- **Action**: CSV/PDF 지원 안내, 무료 월 2회 분석 정책과 구독자 추가 분석 정책 안내.
- **Outcome**: 방문자는 가입 전 업로드 가능 형식과 무료·유료 이용 범위를 이해한다.
- **Exceptions**: 카드사별 파일 형식에 따른 추출 가능 여부는 보장하지 않는다.
- **Display**: CSV/PDF 지원 명시, "무료 월 2회 분석" 문구 명시, "구독 시 추가 분석" 문구 명시,
  월간 구독 결제 금액 명시(랜딩 페이지에 공개).
- **Permissions**: 모든 방문자.
- **Rules**: 무료 제공 횟수는 사용자당 매월 최대 2회로 안내. 유료 구독자는 초과 시 추가 분석
  가능하다고 안내.
- **Data**: 정적 콘텐츠.

### F-MAFWCW. 로그인 및 회원가입 전환 경로

- **Precondition**: 방문자는 랜딩 페이지에 접근할 수 있다.
- **Trigger**: 방문자가 로그인 또는 분석 시작 유도 버튼을 선택한다.
- **Action**: 방문자를 로그인/회원가입 화면으로 이동시킨다.
- **Outcome**: 방문자는 소셜 로그인/회원가입 화면에 도달한다.
- **Exceptions**: 이동 실패 시 재시도 안내.
- **Display**: 주요 영역에 로그인/회원가입 버튼 표시, 계정 접근 필요성을 이해할 수 있는 문구.
- **Permissions**: 비로그인 방문자도 사용 가능.
- **Rules**: 전환 버튼은 로그인/회원가입 화면으로 연결. 랜딩 페이지에서 인증 정보를 직접
  입력/처리하지 않는다.
- **Data**: 전환 버튼은 로그인/회원가입 화면 URL 참조.

## R-TTKAAN. 소셜 로그인 및 사용자 계정

사용자가 소셜 로그인으로 가입/로그인할 수 있도록 하며, 로그인한 사용자는 분석 이용 횟수와
구독 상태를 확인할 수 있어야 한다.

**Acceptance Criteria**
- 신규 사용자는 지원 소셜 로그인으로 계정 생성 가능
- 기존 사용자는 동일 방식으로 재로그인 가능
- 비로그인 사용자가 대시보드 접근 시 로그인 화면으로 이동
- 로그인 후 무료 분석 잔여 횟수/구독 상태 확인 가능
- 안전한 로그아웃 가능

### F-IZGIPZ. 소셜 로그인 및 계정 생성

이메일/비밀번호 회원가입, 구글 외 소셜 로그인 제공자는 포함하지 않는다.

- **Precondition**: 사용자는 로그인/회원가입 화면에 접근할 수 있다. MVP 지원 소셜 로그인
  제공자는 구글만 지원한다.
- **Trigger**: 사용자가 구글 로그인 버튼을 선택한다.
- **Action**: 구글 인증 절차로 이동, 인증 성공 시 구글 계정 식별자로 기존 계정 조회 또는 신규
  계정 생성.
- **Outcome**: 신규 사용자는 계정 생성 후 로그인 상태가 되고, 기존 사용자는 기존 계정으로
  로그인되어 대시보드 접근 가능.
- **Exceptions**: 사용자가 인증을 취소하면 로그인 완료 처리 없이 로그인 화면으로 복귀. 인증/계정
  생성 실패 시 실패 사실과 재시도 안내 표시.
- **Display**: 구글 로그인 버튼 표시, 실패 시 이해 가능한 오류 메시지 + 재시도 동작.
- **Permissions**: 비로그인 방문자도 절차 시작 가능. 로그인 완료 사용자는 본인 계정으로만 접근.
- **Rules**: 동일 구글 계정 식별자는 기존 계정으로 로그인 처리. 인증 성공 시에만 신규 계정
  생성. 구글 계정의 비밀번호는 직접 수집/보관하지 않는다.
- **Data**: 사용자 계정 = {내부 사용자 식별자, 소셜 제공자(구글 고정), 제공자 계정 식별자,
  계정 생성 시각, 최근 로그인 시각}. 제공자 계정 식별자는 중복 판별/인증 연동에 사용.

### F-RIRRKL. 로그인 상태 보호 및 안전한 로그아웃

- **Precondition**: 대시보드는 인증 필요 보호 화면. 사용자는 유효 세션 보유 또는 로그아웃 상태.
- **Trigger**: 비로그인 사용자가 대시보드 URL/인증 필요 기능에 접근하거나, 로그인 사용자가
  로그아웃을 선택한다.
- **Action**: 비인증 사용자를 로그인 화면으로 이동. 로그아웃 요청 시 세션 종료 및 인증 정보
  무효화.
- **Outcome**: 비인증 사용자는 로그인 전까지 대시보드/개인 데이터 접근 불가. 로그아웃 사용자는
  랜딩/로그인 화면으로 이동하며 재접근 시 재로그인 필요.
- **Exceptions**: 세션 만료/무효 시 보호 데이터를 표시하지 않고 로그인 화면으로 이동. 로그아웃
  처리 오류 시 재시도 안내.
- **Display**: 로그인 사용자 접근 화면에 로그아웃 동작 표시. 인증 만료로 이동 시 재로그인 필요
  안내 표시.
- **Permissions**: 대시보드/사용자별 분석 데이터는 인증된 본인만 접근. 비로그인 방문자는
  랜딩/로그인 화면만 접근.
- **Rules**: 보호 화면은 화면 진입 전·데이터 조회 전 인증 상태 확인. 로그아웃 후 기존 세션으로
  보호 화면/데이터 조회 불가.
- **Data**: 인증 세션 = {사용자 식별자, 세션 식별자, 발급 시각, 만료 시각, 유효 상태}. 사용자별
  데이터 조회는 인증 세션의 사용자 식별자 기준으로 제한.

### F-PAOWJD. 계정별 분석 이용 현황 및 구독 상태 조회

분석 횟수 차감, 결제 실행, 구독 상태 변경은 별도 기능(F-ILHNGA, F-UXSBGF, F-QVPIEG) 범위.

- **Precondition**: 사용자는 로그인 상태로 대시보드에 접근. 시스템은 계정별 이용 기록/구독 상태
  보유.
- **Trigger**: 로그인 사용자가 대시보드/계정 이용 현황 영역을 확인한다.
- **Action**: 현재 월 무료 분석 사용/잔여 횟수 조회, 유료 구독 활성 상태 조회.
- **Outcome**: 무료 사용자는 사용/잔여 횟수 확인, 유료 구독자는 구독 상태와 추가 분석 이용
  가능 여부 확인.
- **Exceptions**: 조회 실패 시 권한을 임의 표시하지 않고 새로고침/재시도 안내. 구독 상태 갱신
  중이면 마지막 확정 상태 또는 갱신 중 상태 표시.
- **Display**: 무료 사용자에게 사용/잔여 횟수 명확히 표시. 유료 사용자에게 활성 구독 상태와
  추가 분석 가능 여부 표시. 잔여 0회 시 결제 안내 진입점 표시.
- **Permissions**: 사용자는 자신의 현황만 조회. 관리자는 별도 관리 기능 정의 전까지 타 사용자
  현황 조회 불가.
- **Rules**: 무료 이용 현황은 매월 최대 2회 정책 기준 표시. 유료 구독 상태는 결제 정상 완료 후
  활성화된 경우에만 표시. 표시 데이터는 실제 권한 판정 기준 데이터와 동일해야 함.
- **Data**: 이용 현황 = {사용자 식별자, 대상 월, 무료 사용 횟수, 무료 잔여 횟수}. 구독 정보 =
  {사용자 식별자, 구독 상태, 구독 상품 유형, 상태 갱신 시각}.

## R-ONTTAQ. 카드 내역서 업로드 및 데이터 처리

로그인한 사용자가 대시보드에서 CSV/PDF 카드 내역서를 업로드하면 시스템이 형식을 검증하고
분석 가능한 거래 내역으로 변환한다.

**Acceptance Criteria**
- CSV/PDF 파일 선택 업로드 가능
- 미지원 형식/손상 파일 업로드 시 오류 메시지 표시
- 업로드 처리 중 진행 상태 표시, 중복 분석 요청 방지
- 거래일/가맹점/금액 등 분석 필요 정보 추출
- 데이터 추출 실패 시 분석 미완료 처리 + 재업로드/확인 안내
- 업로드 데이터는 해당 사용자 계정 분석에만 사용되도록 접근 제한

### F-ILFWKT. 카드 내역서 파일 업로드 및 형식 검증

거래 데이터 추출과 AI 인사이트 생성 자체는 포함하지 않는다.

- **Precondition**: 사용자는 로그인 상태로 대시보드 접근, 업로드할 카드 내역서 파일 보유.
- **Trigger**: 사용자가 파일 선택 영역/업로드 버튼을 선택한다.
- **Action**: CSV/PDF 파일 선택·업로드 지원, 형식/읽기 가능 여부 검증, 검증·처리 중 진행 상태
  표시, 동일 분석 요청 중복 시작 제어.
- **Outcome**: 유효 파일은 거래 내역 추출 처리 대상으로 전달. 업로드 시작/검증 결과 측정용
  이벤트 기록.
- **Exceptions**: CSV/PDF 외 파일 업로드 시 지원 형식 안내 오류 메시지. 읽기 불가/손상 파일은
  확인·재업로드 안내. 처리 중 파일이 있으면 중복 요청 차단 + 현재 처리 상태 안내.
- **Display**: 업로드 영역에 CSV/PDF 지원 형식 표시. 처리 중 진행 상태 표시. 실패 시 원인과
  재시도 방법을 이해하기 쉬운 문장으로 표시. 모바일 웹에서도 동일한 업로드 영역을 쓰며,
  파일 선택은 모바일 브라우저의 기본 파일 선택기(파일 앱 등)로 연결된다.
- **Permissions**: 로그인 사용자만 업로드 가능.
- **Rules**: 지원 형식은 CSV/PDF로 제한. 검증/처리 실패 요청은 분석 대상으로 넘기지 않음.
  업로드 처리 중 동일 사용자의 중복 분석 요청 불허.
- **Data**: 업로드 파일은 사용자 계정 식별자 + 처리 상태와 연결. 원본 형식은 CSV 또는 PDF.
  업로드 최대 용량은 20MB이며, 초과 시 지원 형식 안내와 동일한 오류 메시지로 처리한다.

## R-GURVDX. AI 소비 분석 및 인사이트 생성

추출된 카드 거래 내역을 AI로 분석하여 카테고리별 지출, 이상 지출, 절약·관리 추천을 반드시
포함한 인사이트를 생성한다.

**Acceptance Criteria**
- 전체 지출 요약 + 카테고리별 지출 금액/비중 포함
- 평소와 다른 이상 지출/주의 필요 거래 제시

### F-ILHNGA. 무료 분석 이용 횟수 관리

유료 구독자의 추가 분석 권한/결제 처리는 별도 기능(F-UXSBGF, F-QVPIEG) 범위.

- **Precondition**: 사용자 로그인 상태. 활성 유료 구독 상태가 아니며 무료 정책 적용 대상.
  무료 횟수 초기화 기준일은 매월 1일이다.
- **Trigger**: 사용자가 분석을 요청하거나 대시보드에서 이용 현황을 확인한다.
- **Action**: 분석 요청 전 무료 잔여 횟수 확인, 분석 정상 완료 시에만 1회 차감, 현재 월 사용/
  잔여 횟수 갱신.
- **Outcome**: 사용자는 월 최대 2회 무료 분석 이용. 분석 완료 이벤트와 차감 결과 기록.
- **Exceptions**: 분석/AI 결과 생성 실패 시 횟수 차감하지 않음. 잔여 0회면 분석 실행하지 않음.
- **Display**: 대시보드에 현재 월 사용/잔여 횟수 표시. 잔여 0회면 구독 필요 안내 표시.
- **Permissions**: 사용자는 자신의 이용 현황만 조회. 관리자는 운영 목적상 사용자별 기록 조회
  가능.
- **Rules**: 사용자당 매월 최대 2회. 정상 완료된 분석에 대해서만 차감. 잔여 0회 사용자의 요청은
  결제 전까지 제한.
- **Data**: 사용자별 = {월간 무료 사용 횟수, 잔여 횟수, 초기화 기준일}. 분석 요청별 = {완료 상태,
  무료 횟수 차감 여부}.

### F-UXSBGF. 월간 구독 결제 진행

결제수단 등록, 환불, 영수증 발급의 상세 정책은 범위 외 (해지 자체는 F-QVPIEG 범위에서 지원).

- **Precondition**: 사용자 로그인 상태. 무료 잔여 횟수를 모두 사용했거나 구독 결제 화면으로
  이동함.
- **Trigger**: 사용자가 무료 소진 안내 또는 대시보드에서 월간 구독 결제 버튼을 선택한다.
- **Action**: 구독 상품 결제 금액과 추가 분석 이용 조건 표시, Polar(외부 결제 서비스) 결제
  절차로 이동 및 결과 확인, 결제 성공 확인 시 구독 상태를 활성으로 갱신. 구독자는 무료 2회
  소진 후 추가로 월 2회까지 분석 가능(월 최대 4회).
- **Outcome**: 결제 정상 완료 사용자는 활성 월간 구독 상태가 됨. 결제 시작/성공/실패 이벤트
  기록.
- **Exceptions**: 결제 실패/취소 시 구독 상태 미변경. 실패 시 사실 + 재시도 방법 안내.
- **Display**: 결제 화면에 상품명, 결제 금액, 추가 분석 이용 조건(월 2회 추가) 표시. 완료/실패
  결과를 이해 가능한 문구로 표시. 결제는 Polar 결제 화면으로 이동해 진행한다.
- **Permissions**: 로그인 사용자만 자신의 계정으로 결제 진행. 사용자는 자신의 결제 결과/구독
  상태만 확인.
- **Rules**: 정상 확인된 결제에 대해서만 구독 활성화. 결제 실패/취소는 추가 분석 권한 부여 안 함.
  잔여 0회 사용자는 결제 완료 전 분석 실행 불가. 구독자의 추가 분석 잔여 횟수도 무료 횟수와
  동일하게 매월 1일 기준으로 초기화된다.
- **Data**: 구독 상품 = {식별자, 결제 금액, 이용 조건(월 추가 2회)}. 결제 요청 = {식별자, 상태,
  완료 시각, 사용자 식별자, Polar 결제/구독 참조 식별자}.

### F-QVPIEG. 구독 상태 기반 추가 분석 권한 부여 및 해지

구독 결제/재결제 자체 처리는 F-UXSBGF 범위. 환불 상세 정책은 범위 외.

- **Precondition**: 사용자는 월간 구독 결제를 정상 완료. 시스템에 구독 상태/분석 이용 권한 저장.
- **Trigger**: 사용자가 대시보드에서 구독 상태를 확인하거나 무료 소진 후 분석을 요청하거나,
  구독 해지를 요청한다.
- **Action**: 분석 요청 시점에 활성 구독 상태 검증, 활성 구독 사용자에게 추가 분석 이용 권한
  부여, 대시보드에 현재 구독 상태 표시. 사용자가 해지를 요청하면 자동 갱신을 중단하도록 Polar에
  반영하고 해지 예약 상태를 표시.
- **Outcome**: 활성 월간 구독 사용자는 구독 이용 조건에 따라 추가 분석 이용 가능. 구독 상태
  조회/구독 사용자 분석 완료 이벤트 기록. 해지 요청 사용자는 현재 결제 주기 종료 시점까지 구독
  혜택을 유지한 뒤 자동 갱신 없이 종료된다.
- **Exceptions**: 구독 상태 확인 불가 시 추가 분석 미실행 + 재시도 안내. 비활성/결제 실패
  사용자는 추가 분석 권한 없음. 해지 요청 처리 실패 시 실패 사실과 재시도 안내 표시.
- **Display**: 대시보드에 현재 구독 상태 명확 표시. 활성 구독자에게 추가 분석 가능 상태 표시.
  해지 예약 상태와 혜택 종료 예정일 표시.
- **Permissions**: 사용자는 자신의 구독 상태/이용 권한만 확인·해지 요청. 관리자는 운영 목적상
  조회 가능.
- **Rules**: 추가 분석 권한은 활성 구독이 확인된 사용자에게만 부여. 결제 완료 후 구독 상태 갱신
  시 추가 분석 이용 가능. 비활성 확인 시 무료 분석 정책 적용. 구독은 매월 자동 갱신되며, 사용자
  해지 요청 시 다음 결제 주기부터 갱신하지 않는다(현재 주기 종료까지는 활성 유지).
- **Data**: 사용자별 = {구독 상태(활성/해지 예약/비활성), 구독 시작/종료(예정) 시각, 자동 갱신
  여부, 결제 참조 정보}, {추가 분석 권한 상태, 권한 검증 시각}.
