# Finsight PRD

> 출처: Manyfast 프로젝트 "Finsight: 카드 내역 기반 AI 소비 분석 및 인사이트 SaaS"
> (`472e20e8-ec37-444b-a58a-d10f89194f7d`). 상세 기능/개발 스펙은 [feature-spec.md](./feature-spec.md),
> 화면 흐름은 [user-flow.md](./user-flow.md) 참고.

## 한 줄 정의

카드 내역서(CSV/PDF)를 업로드하면 AI가 소비 데이터를 분석해 카테고리별 지출, 이상 지출,
실행 가능한 절약·관리 추천을 대시보드 한 화면에서 제공하는 SaaS.

## Goal

사용자가 자신의 카드 내역서(CSV 또는 PDF)를 업로드하면 AI가 소비 데이터를 자동으로 분석하여
카테고리별 지출 현황, 평소와 다른 이상 지출, 실행 가능한 절약·관리 추천을 한 화면에서 제공한다.
사용자는 복잡한 수작업 없이 자신의 소비 습관을 파악하고 지출에 대한 인식을 높일 수 있다.

## Background

개인 소비자는 카드 내역을 보유하고 있어도 전체 지출 구조와 반복적인 소비 습관을 체계적으로
파악하기 어렵다. 기존에는 내역을 직접 분류하고 합산해야 하므로 분석에 시간과 노력이 필요하다.
Finsight는 카드 내역 파일을 기반으로 AI 소비 분석을 제공하여 개인 소비자와 사회 초년생이 자신의
지출을 쉽게 이해하도록 지원한다.

**MVP 범위**: 랜딩 페이지, 로그인, 결제, 로그인 후 대시보드. 무료 사용자는 월 2회 분석, 유료
구독자는 추가 분석 이용. AI 인사이트 외 별도 추가 기능은 MVP 범위에 포함하지 않는다.

## Problem / Solution

**사용자 문제**: 사용자는 카드 내역을 통해 실제로 어디에 얼마를 지출하는지 한눈에 확인하기
어렵다. 불필요한 소비나 평소와 다른 지출을 발견하려면 내역을 직접 정리·분류해야 하므로 시간이
많이 들며, 분석 결과를 실제 절약이나 소비 관리 행동으로 연결하기도 어렵다.

**해결 방안**: 사용자가 CSV 또는 PDF 형식의 카드 내역서를 업로드하면 Finsight가 거래 내역을
추출하고 AI로 분석한다. 대시보드 한 화면에서 카테고리별 지출 내역, 이상 지출, 실행 가능한
절약·관리 추천을 제공한다. 무료 사용자는 월 2회, 유료 월간 구독자는 추가 분석을 이용할 수 있다.

**차별점**: 단순한 지출 합계·차트 제공을 넘어 소비 패턴을 해석하고 이상 지출과 구체적인 행동
추천까지 연결한다. CSV뿐 아니라 PDF 카드 내역서도 지원해 입력 장벽을 낮추고, 분석 결과를 여러
페이지로 분산하지 않고 대시보드 한 화면에 통합한다.

## Target User & Scenario

**타겟 사용자**: 자신의 소비 습관을 관리하고 싶은 개인 소비자와 사회 초년생. 월급/고정 수입은
있지만 월말에 돈이 어디에 쓰였는지 명확히 파악하지 못하는 20~30대가 핵심 대상. 금융 전문
지식이나 스프레드시트 활용 능력이 높지 않아도 사용할 수 있어야 한다.

**핵심 시나리오**:
1. 랜딩 페이지에서 핵심 가치, 무료 분석 횟수, 유료 구독 정책 확인
2. 소셜 로그인으로 가입/로그인
3. 대시보드에서 CSV/PDF 카드 내역서 업로드
4. 시스템이 파일 검증 → 거래 내역 추출 → AI 분석 실행
5. 대시보드 한 화면에 카테고리별 지출, 이상 지출, 절약·관리 추천 표시
6. 사용자가 결과를 확인하고 소비 현황 파악
7. 무료 횟수 소진 시 월간 구독 결제 진행
8. 구독자는 결제 후 추가 분석 이용

## Success Metrics (KPI)

- 랜딩 페이지 방문자 → 회원가입 전환율
- 회원가입 → 첫 카드 내역 업로드 전환율
- 업로드 → 분석 완료율 (MVP 초기 우선 검증 지표)
- 분석 결과 조회율 (MVP 초기 우선 검증 지표)
- 무료 사용자 월 2회 분석 소진율
- 무료 → 유료 월간 구독 전환율
- 유료 구독 유지율
- 분석 결과 사용자 만족도

## Risks

- 카드사별로 CSV/PDF 형식이 달라 데이터 추출이 실패할 수 있음
- AI가 상점명/카테고리를 잘못 해석하면 인사이트 신뢰도 저하
- 개인 금융 데이터 포함 → 파일 보안, 접근 통제, 보관/삭제 정책 미흡 시 개인정보 유출 위험
- AI 분석 비용이 사용자 분석 횟수보다 빠르게 증가할 위험, 분석 시간/안정성 문제 시 이탈
- 무료/유료 분석 권한 관리 오류 시 결제 신뢰도·매출 영향

## Scope Attributes

- **Category**: finance
- **Roles**: 사용자 (LUJDEJ), 관리자 (HZPRSS) — MVP는 사용자 역할 중심, 관리자 기능은 최소
- **Devices**: 웹 (DCLLDB) — 데스크톱 웹 + 모바일 웹(반응형) 모두 포함. Mobile (GOQQWM)은
  네이티브 앱이 아니라 이 반응형 모바일 웹을 가리킨다. 별도 네이티브 앱(iOS/Android)은 MVP
  범위 아님.

## Product Decisions (확정)

구현 착수 전 확정된 정책. 이전에는 "Open Product Decisions"로 미확정 상태였으나 아래와 같이
확정되었다. ADR.md/ARCHITECTURE.md 작성 시 이 결정을 근거로 삼는다.

1. **월간 구독가 공개 시점** — 랜딩 페이지에 결제 금액 공개.
2. **업로드 파일 최대 용량** — 20MB.
3. **지원 소셜 로그인 제공자** — 구글만 지원 (MVP).
4. **무료 분석 횟수 초기화 기준일** — 매월 1일.
5. **월간 구독자의 추가 분석 한도** — 무료 2회 소진 후 추가로 월 2회 (구독자 월 최대 4회).
6. **결제 처리 방식** — Polar(외부 결제 서비스) 연동.
7. **구독 갱신·해지 정책** — 자동 갱신 지원, 사용자 해지(구독 취소) 지원.
8. **지원 디바이스** — 데스크톱 웹 + 모바일 웹(반응형 레이아웃). 네이티브 앱은 MVP 범위
   아님 (상세: [UI_GUIDE.md의 반응형 / 모바일 웹](./UI_GUIDE.md#반응형--모바일-웹)).

## Not in Scope (MVP)

- 카드사 원본 카테고리 수정, 사용자의 카테고리 직접 편집
- 부정 거래 확정 판단, 카드사 신고 대행
- 투자·대출·보험 등 전문 금융상품 추천/권유
- 결제수단 등록, 환불, 영수증 발급의 상세 정책 (해지 자체는 지원, 환불·영수증 세부 정책은 후속 결정)
- 이메일/비밀번호 회원가입, 구글 외 소셜 로그인 (MVP는 구글 로그인만 지원)
- 네이티브 모바일 앱(iOS/Android). 모바일은 반응형 웹으로만 지원
